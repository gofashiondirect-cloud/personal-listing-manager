# Documentation criteria (sources: Diátaxis, README conventions, Keep a Changelog)
- DOC-01 README: what it is, how to install, run, test and deploy, in that order.
- DOC-02 Setup: required environment variables listed (with an .env.example), no secrets.
- DOC-03 Changelog: user-facing changes recorded at the top of CHANGELOG.md.
- DOC-04 Code comments: explain why, not what; public functions have a short docstring.
- DOC-05 API docs: every endpoint's request, response and errors documented where the project keeps API docs.
- DOC-06 Decisions: significant architecture decisions recorded (ADR or CLAUDE.md conventions).
- DOC-07 User help: user-facing features that need explaining have help text or a help page.
- DOC-08 Accuracy: docs updated in the same change as the behaviour they describe.
