Personal Listing Manager

Privacy & Terms

Personal Listing Manager is a private tool used only by the shop owner to manage their own shop listings and inventory through Etsy's official API.

Access

This application is not public and is not offered to other sellers. Only the shop owner and app developer may access the application.

Data Used

The application may access listing and inventory data needed to manage the owner's own shop, including listing details, SKUs, prices, quantities, product details, and listing status.

How Data Is Used

Shop data is used only to provide private listing and inventory management functions for the shop owner. The application does not sell, rent, share, or use Etsy data for advertising.

Authorization

The application uses OAuth authorization and requests only the permissions needed to manage the owner's own listings and inventory. API credentials and access tokens must not be shared publicly or with unauthorized parties.

No Scraping

The application uses Etsy's official API and does not use screen scraping, automated crawling, or unofficial internal Etsy endpoints.
